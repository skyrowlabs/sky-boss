# Occasional Reports — One-Time Deep Dives

Point-in-time investigations: sweeps, audits, benchmarks, and hunts that found
nothing. Date-based filenames (`YYYY-MM-DD-slug.md`), because these are moments
rather than windows — but each names the build it analyzed in its header:

```
> **Analyzed at:** v1.4.0 +38 commits (`abc1234`)
```

**Read this folder before starting a sweep.** Re-running an audit cold is the
most expensive way to learn what an `ls` would have told you, and a stale report
here is *visibly* stale rather than quietly wrong.
