# Templates

Scaffolding shipped with the tool, copied into your `TB_HOME` by `tb run init-home`.

These are the **project's** files: reviewed and versioned alongside the code that reads them. The
filled-in copies they become are **yours** and live in `~/.tackle-box/`, which is a separate git
repository. See the `operator-home` feature doc.

Editing a template changes what future scaffolds produce. It does not touch a home that already
exists — nothing here reaches back into your content.
